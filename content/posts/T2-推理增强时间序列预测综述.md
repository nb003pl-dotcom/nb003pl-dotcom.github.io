# Agenthon 2026 Track 2 技术综述：推理增强的时间序列概率预测

> 课题组内部学习笔记 · 2026 年 11 月
> 面向赛道：Agenthon 2026（NeurIPS 2026，"可验证 AI 在量化金融中的应用"）Track 2 — Forecasting（推理增强时间序列预测）
> 竞赛主页：https://www.agenthon.net/

## 引言：为什么 Track 2 值得认真对待

Agenthon 2026 的 Track 2 把一个看似"经典"的任务——时间序列预测——重新包装成了极具当代特征的研究问题：输入是**面板时间序列 + 带时间戳的文本语料（如新闻）**，输出必须是**未来面板的概率分布**，评估用 **CRPS composite**，准入门控包括 **as-of cutoff（严格时点截止）** 与 **calibration（校准检查）** 两道闸。运行环境是沙盒 Docker、无通用互联网、仅可调用受限的 House Nemotron LLM。截至写作时，排行榜头部 CRPS 约 **−0.947**，87 支队伍，且分差为四赛道中最大——这意味着方法论的差异在分数上被放大了，是一个"方法红利"仍然丰厚的赛道。

更值得注意的是，竞赛明确把"**文本信息是否带来预测提升（information uplift）**"列为研究目标（虽然不计入主分数）。这等于在追问一个 2023 年以来悬而未决的问题：LLM 与文本究竟能不能给数值时序预测带来净增量？本综述围绕这一问题展开。

## 一、任务解读：分布预测 + 文本增强 + 时点纪律的三位一体

### 1.1 为什么是"概率分布预测"而非点预测

金融面板（收益率、波动率、成交量等）本质是高噪声、低信噪比、厚尾的非平稳过程。点预测（mean/median）在 CRPS/MSE 下会被极端值主导，且无法支撑下游的仓位 sizing 与风控。Track 2 要求输出分布，本质上是要求模型对**不确定性本身**建模，而非只对期望建模。

CRPS（Continuous Ranked Probability Score）源自气象预报（1970s），定义为预测 CDF $F$ 与观测值 $y$ 的退化解之间的平方面积：

$$\text{CRPS}(F, y) = \int_{-\infty}^{\infty} (F(x) - \mathbf{1}\{x \geq y\})^2 dx$$

它是**严格 proper scoring rule**，即诚实报告真实后验分布是该规则的纳什均衡——这是它在概率预测评估中的核心地位来源。它同时奖励**准确性**（分布集中在真值附近）与**校准性**（分布尾概率与经验频率一致）。CRPS 对应的离散化形式即 quantile loss（pinball loss）之和，因此实践中常以多分位数输出 + pinball 训练来逼近。CRPS composite 通常指对不同分位/不同序列的加权聚合。排行榜用负号（−0.947）说明分数越大（越接近 0 的负值）越好，这与 CRPS 越小越好的惯例相反，需在实现时核对符号约定。

### 1.2 文本增强：从"有没有用"到"在什么条件下用"

带时间戳的新闻语料是 Track 2 区别于普通时序 benchmark 的关键变量。文本信息可能贡献于三类信号：(i) 事件驱动冲击（财报、政策、并购）；(ii) 情绪与叙事漂移；(iii) 因果结构变化提示（regime shift）。但 LLM 提取这些信号的成本（token、延迟、噪声）很高，且现有证据对"文本是否稳定带来 uplift"存在严重分歧（见 §3.3）。竞赛把它作为研究目标而非计分项，是务实的——避免选手为了刷分而过拟合校准门控。

### 1.3 时点纪律（as-of cutoff）：金融 ML 的第一原则

"as-of cutoff"门控要求：在预测 $t$ 时刻的分布时，模型可见的所有数据（数值与文本）的**时间戳必须 ≤ t**。这听起来像废话，但金融 ML 史上最大的坑几乎都在这里。López de Prado 在 *Advances in Financial Machine Learning*（2018）中系统指出，标准 k-fold CV 在金融时序上会因为样本重叠与序列相关而**系统性高估**样本外表现，并提出 **Purged K-Fold CV** 与 **Combinatorial Purged CV**，通过主动剔除标签窗口与测试集重叠的训练样本（purging + embargoing）来遏制泄漏。Track 2 把这一纪律前置为准入门控，本质上是把"可复现、可答辩"作为参赛前提——任何隐式 look-ahead 都会在门控阶段被拒。

### 1.4 校准门控：防止"分位数造假"

仅有 CRPS 不够。一个模型可以在 CRPS 上好看但**条件错校准**——例如整体覆盖率达标，但在高波动期系统性欠覆盖。calibration gate 通常检验 PIT（probability integral transform）均匀性、或分位覆盖的条件偏差。这迫使选手不能只优化 pinball loss，还需做 conformal 校准或 isotonic 后处理。

三位一体的设计逻辑：**分布预测提供不确定性语言，文本增强提供信息增量假说，时点纪律 + 校准门控保证结论可信**。任何一环塌方都会让"文本有用"的结论不可证伪。

## 二、技术方向地图

下面把 Track 2 相关的方法论拆成六个子方向。它们并非互斥，实际系统往往是组合体。

### (a) 时间序列基础模型（TSFM）

2023 年底起，"时序版 GPT"成为显学。核心范式：在大规模、跨域时序语料上预训练一个 Transformer，支持 zero-shot 预测。

| 模型 | 来源 / 年份 | 关键设计 | 概率输出 |
|---|---|---|---|
| **TimeGPT-1**（arXiv:2310.03567） | Nixtla, 2023 | 首个商用 TSFM，encoder-decoder，支持外生变量；API-only | 内置 conformal prediction |
| **Lag-Llama**（arXiv:2310.08278） | 多机构, 2024 | 首个开源 TSFM，LLaMA 解码器 + lag-based 分词 | 概率（分位数） |
| **TimesFM**（arXiv:2310.10688） | Google, ICML 2024 | decoder-only，patched-decoder，100B 时间点预训练 | 点 + 概率 |
| **Chronos**（arXiv:2403.07815） | Amazon, 2024 | T5 族（20M–710M），scaling+量化分词成离散 token，next-token 预测；42 数据集 zero-shot 强 | 概率（采样） |
| **Moirai**（arXiv:2402.02592） | Salesforce, ICML 2024 oral | any-variate attention，混合参数分布（Student-T/Normal），LOTSA 27B 观测，Uni2TS 库 | 原生分布 |
| **Moirai-MoE**（arXiv:2410.10469） | Salesforce, NeurIPS 2024 WS | token 级 sparse MoE，39 数据集 | 原生分布 |
| **Time-MoE**（arXiv:2409.16040） | Princeton 等, ICLR 2025 | 首个十亿级（2.4B 总参/1B 激活）TSFM，Time-300B 数据集，多分辨率预测头 | 概率 |
| **MOMENT** | CMU, ICML 2024 | 通用 in-context 学习，覆盖预测/插补/异常检测 | 概率 |
| **Timer / Timer-XL** | 清华, ICML 2024 / ICLR 2025 | 生成式 Transformer，TimeAttention 长上下文多变量 | 概率 |

**关键趋势：** (1) **"小即是美"反 scaling law**——Moirai 2.0、Chronos 2、TimesFM 2.x 普遍在缩小参数的同时提升精度，因为时序信噪比低，大模型易过拟合；(2) 架构趋同于"patching 分词 + 归一化 + Transformer 主干"；(3) **概率输出成为标配**，Moirai 与 Lag-Llama 原生支持分位/分布，对 Track 2 直接可用。

### (b) LLM 推理增强时序预测

这一方向把"语言模型"当作时序的推理引擎，而非纯数值拟合器。可分三档：

**重编程 / 对齐档（让 LLM 听懂时序）：**
- **Time-LLM**（Jin et al., ICLR 2024）：冻结 LLM 主干，训练轻量 reprogramming 层把时序嵌入对齐到文本原型空间，prompt-as-prefix，不微调 backbone。
- **PromptCast**：把数值时序转成自然语言 prompt，把预测变成 sentence-to-sentence 生成，配套 PISA 数据集。
- **LLMTime**（Gruver et al., NeurIPS 2023，arXiv:2310.07820）：纯 zero-shot，把时序值逐数字编码为文本，靠 next-token 生成多模态分布。开启乐观浪潮。
- **TEMPO**（arXiv:2310.04948，ICLR 2024）：冻结 GPT-2 + prompt tuning + LoRA，把输入分解为 trend/seasonal 再分别处理。
- **TimeCMA**（arXiv:2406.01638，AAAI 2025）：双分支编码（时序 inverted Transformer + LLM prompt），用跨模态对齐模块从 prompt 嵌入中"检索"高质量纯时序表示，last-token 设计降算力。
- **Context-Alignment**（ICLR 2025，openreview syC2764fPc）：把整段时序融入语言语境而非词级对齐，强调 LLM 的语言逻辑而非 token 嵌入。

**推理 / 慢思考档（让 LLM 想清楚再答）：**
- **Time-R1**（arXiv:2506.10630，2025）：把预测重述为分步推理 + 多模态理解，两阶段——SFT warmup + RL 微调；提出 **GRIP**（group-based relative importance for policy optimization）用非均匀采样鼓励探索有效推理路径。是"o1/R1 风格推理用于时序"的代表性工作。
- **TimeReasoner**（arXiv:2505.24511，2025）：实证研究，测试 ChatGPT-o1/DeepSeek-R1 类慢思考模型在 zero-shot 时序推理上的能力，框架含原始尺度序列、时间戳特征、语境特征描述三要素。
- **STRIDE**（arXiv:2605.08625，2026）："Strategic Time-series Reasoning Injected via Distilled Embeddings"，把 LLM 推理轨迹蒸馏进轻量 LLM，再将其 pooled hidden states 作为连续跨模态先验动态投影进数值编码器，与 Chronos-2/Timer-S1 联合训练（cross-entropy + quantile loss）。**在 GIFT-Eval 排行榜 #1（0.625 MASE, 0.423 CRPS）**——对 Track 2 极具参考价值。

**批判档（泼冷水）：**
- **"Are Language Models Actually Useful for Time Series Forecasting?"**（Tan et al., NeurIPS 2024，arXiv:2406.16964）：大规模评测后直言"预训练 LLM 对时序预测**尚未有用**"，许多 prior 成就被高估，简单/专用模型常胜出。
- **"Language Models Still Struggle to Zero-shot Reason about Time Series"**（Merrill et al., EMNLP Findings 2024）：LLM 即便基本零样本推理也吃力。
- **"Revisiting LLMs as Zero-Shot Time-Series Forecasters"**（Park et al., ACL 2025）：重审 LLMTime，质疑其鲁棒性与泛化。

这些批判的共识：**直接拿通用 LLM 做时序不如专用 TSFM**；乐观派的增益多来自评测不严或数据泄漏。Track 2 的沙盒 + as-of cutoff 恰好是检验这一争议的理想场所。

### (c) 文本 + 数值多模态金融预测

历史脉络从词典/计数法 → 早期深度 NLP → LLM 时代：

- **Tetlock (2007)**，*"Giving Content to Investor Sentiment: The Role of Media in the Stock Market"*，*Journal of Finance*——奠基性工作，用《华尔街日报》专栏文本的悲观情绪预测市场收益，奠定"文本可预测资产"的实证基础。
- **FinBERT / FinBERT-LSTM**：BERT 在金融语料上微调，再与 LSTM 融合新闻情绪做股价预测，代表 LLM 前的一波。
- **FinGPT**（arXiv:2412.10823，2024–25）：用 LLM 情绪 + **新闻传播动力学**（dissemination dynamics）增强股价运动预测，被引较多。
- **LLMFactor**（ACL 2024，东京大学）：顺序知识引导 prompt 从 LLM 抽因子做股价运动预测；作者承认需直面 EMH 挑战。
- **Officioso et al. (2026)**，*Information Sciences*：多模态框架，融合传统经济指标与 LLM 情绪分。
- **Davidovic et al. (2025)**，*MDPI JRFM*：综述新闻情绪与市场动态的 ML 方法。
- **"Sentiment trading with large language models"**（OpenReview, 2024）：评估 LLM 做美股新闻情绪交易的有效性。

**正反证据并存：** 一面，FinGPT/LLMFactor 报告正向 uplift；另一面，**Nature (2025)** *"Stock market trend prediction using deep neural network via chart analysis: a practical method or a myth?"*（*Humanities and Social Sciences Communications*）发现主流 DNN/LSTM 股价预测研究**制造 false positive**，且在真实噪声市场中 vanilla DNN 预测力**极小**，并质疑 GPT/Llama/DeepSeek 能否推断集体人类决策。EMH 与随机游走理论（Fama 1970；2013 诺奖评语"几乎无方法能准确预测短期股债方向"）构成最强先验反对意见。

实践含义：**文本 uplift 不会免费**。它更可能出现在事件密集、信息不对称强、叙事驱动强的子集（小盘、题材股、事件窗口），而非全市场全时段。Track 2 的 information uplift 分析应做**条件化**分解（按波动率/事件密度分桶），而非给一个全局数字。

### (d) 概率预测与校准方法

- **分位数回归 / pinball loss**：最直接的分布输出方式，对一组分位 $\{q_\alpha\}$ 训练，再插值成 CDF。
- **参数分布头**：如 DeepAR 的学生-t/负二项，或 U-Net 输出 shifted gamma（见淮河流域降水后处理案例）。Moirai 用混合参数分布。
- **Conformalized Quantile Regression (CQR)**（Romano, Patterson & Candès, NeurIPS 2019）：把分位数回归与 conformal prediction 结合，得到**有限样本覆盖保证**的自适应预测区间，弥补纯 QR 在小样本/误设下校准差的问题。
- **Adaptive Conformal Inference**（Gibbs & Candès, NeurIPS 2021）：处理分布漂移下 conformal 的交换性破坏，提供在线自适应覆盖，对非平稳金融时序至关重要。
- **Distributional conformal / HPD 校准**：把 conformal 从点区间扩展到对**整个预测分布**做校准（如 C-USIM，arXiv:2609.34887），处理"点准但分布错校"。
- **PIT 均匀性检验**：经典校准诊断。

Track 2 的 calibration gate 很可能落到 PIT 或条件覆盖检验上，因此**CQR + adaptive conformal 后处理**是性价比极高的工程组合：TSFM 出原始分布 → conformal 校准 → 输出。但需注意 conformal 在 as-of 截止下需用**滚动校准集**，且校准集本身不能泄漏未来。

### (e) 防泄漏评估纪律

- **López de Prado (2018)**，*Advances in Financial Machine Learning*：Triple Barrier 标签、Meta-Labeling、Purged K-Fold CV、Combinatorial Purged CV、MDI/MDA 特征重要性。系统论证标准 CV 在金融时序上的失效与对策。
- **Point-in-time 数据库**：每条记录带"as-of"时间戳，查询时按预测时点回溯可见快照（如 Bloomberg 的 PIT、Bissam 提到的 as-of join）。特征工程中任何"用 t 时刻不可得的聚合/归一化统计"都构成泄漏。
- **Embargo**：在 purging 之外，对测试集前后再留缓冲，避免标签窗口边缘泄漏。
- **Walk-forward / rolling**：与 purged CV 互补的时序评估骨架。

对 Track 2 的直接启示：(i) 训练/校准/测试切分必须沿时间轴，且校准集要独立于 conformal 校准用的 split；(ii) 文本特征（情绪、事件 embedding）若用全局词典/全局统计即泄漏——必须用滚动估计；(iii) 多序列面板的归一化（z-score）若用未来均值/方差即泄漏——用 expanding window。

### (f) 代理化预测流水线（Agentic Forecasting）

2025 年起，"LLM agent 当 AutoML 规划器"成为新范式，对 Track 2 的沙盒 agent 设定高度契合：

- **"Empowering Time Series Forecasting with LLM-Agents"**（arXiv:2508.04231，2025）：LLM agent 作为 AutoML 规划器，自动完成特征工程 + 模型架构搜索。
- **TS-Agent / "Structured Agentic Workflows for Financial Time-Series"**（NeurIPS 2025）：模块化 agentic 框架，覆盖金融时序的数据预处理、特征工程、建模。
- **AutoML-Agent**（ICML 2025）：多 agent LLM 框架，自动化全流程 AutoML，14 数据集 7 任务成功率优于基线。
- **Awesome-Agentic-Time-Series**（GitHub 综述仓库，2026 配套 survey）：追踪 agentic 时序系统。

Agent 化的价值在 Track 2 体现为：(i) 在沙盒内自动编排"TSFM 预测 → 文本 LLM 抽信号 → 融合 → conformal 校准"流水线；(ii) 自动做 as-of 切分与泄漏自查；(iii) 用 House Nemotron 做受限推理而非开放联网。风险：agent 的不稳定性与 token 预算——需把"重"推理（新闻摘要、事件抽取）离线预计算进 Docker 镜像，运行时只做轻量融合。

## 三、相关研究现状：正反证据并陈

### 3.1 时序基础模型：成熟度最高，但金融域是短板

TSFM 在通用 benchmark（GIFT-Eval、TIME、fev-bench）上已能 zero-shot 超越很多 full-shot 专用模型，Chronos 在 42 数据集、Moirai 在 M4/M5 均有强表现。但金融时序（高频、厚尾、低信噪比、强非平稳）是 TSFM 的弱区——预训练语料里金融占比有限，且金融的"可预测部分"多被 EMH 套利掉。Time-MoE 的 Time-300B 虽含金融域，但 zero-shot 到具体面板仍需 domain adaptation。**Moirai/Time-MoE 原生分布输出 + 多变量支持**对 Track 2 最直接可用。

### 3.2 LLM 增强预测：争议最大，方向最热

乐观派（Time-LLM、TEMPO、TimeCMA、STRIDE）报告 LLM 带来增益；悲观派（Tan et al. NeurIPS 2024、Merrill EMNLP 2024、Park ACL 2025）认为增益被高估。调和点：**LLM 的价值不在数值拟合，而在推理与跨模态对齐**。STRIDE 的成功（GIFT-Eval #1）恰恰证明——把 LLM 推理蒸馏成连续先验注入 TSFM，比让 LLM 直接吐数字更靠谱。Time-R1 的 RL 微调路线则代表"让模型学会先推理再预测"的新范式，但训练成本与泛化性待验。

### 3.3 文本 uplift：条件性存在，全局性存疑

正向：Tetlock (2007) 奠基、FinGPT、LLMFactor、Officioso (2026) 均报告文本/情绪有预测力。反向：Nature (2025) 指出 DNN 股价预测制造 false positive；EMH 与随机游走是强先验反证。**最可信的结论**：文本 uplift 是**条件性**的——在事件窗口、小盘、叙事驱动强的子集显著，在全市场宽基指数上微弱甚至为负。Track 2 的 information uplift 分析应据此设计分层评估，而非追求一个全局 uplift 数字。

### 3.4 概率校准：工具齐备，工程化不足

CQR、adaptive conformal、distributional conformal 理论成熟，但在金融时序上的工业落地案例仍少，主要因为非平稳 + 厚尾让 marginal coverage 易达标、conditional coverage 难达标。**这是 Track 2 拉开分差的关键变量之一**——头部队伍很可能在 conformal 后处理 + 条件校准上做了细致工程。

### 3.5 防泄漏：原则清晰，细节致命

López de Prado 的 purged CV 已是行业常识，但文本特征的泄漏更隐蔽（全局词典、全局 TF-IDF、LLM prompt 里混入未来新闻）。Track 2 的 as-of gate 是硬门控，靠门控通过即可，但 information uplift 结论的可信度取决于**文本特征构建是否也守时点纪律**。

### 3.6 Agent 化：早期原型，潜力大

TS-Agent、AutoML-Agent 已验证 agentic AutoML 可行，但金融时序领域的端到端 agentic 预测系统仍属原型期。Track 2 的沙盒 + 受限 LLM 设定天然适合 agent 编排，是"以赛促研"的典型场景。

---

## 四、应用成熟度评估

按"学术研究 / 原型 / 早期落地 / 成熟"四档：

| 子方向 | 成熟度 | 说明 |
|---|---|---|
| 时序基础模型（TSFM） | **早期落地** | TimeGPT 已商用 API；Chronos/Moirai 开源可用；但金融域 zero-shot 仍弱，需 domain adapt。买方多用作 baseline 与特征生成器，少作终端预测器。 |
| LLM 重编程/对齐预测 | **原型** | Time-LLM/TEMPO/TimeCMA 学术验证充分，但工业落地受算力与稳定性制约；批判文献削弱信心。 |
| LLM 推理增强（慢思考） | **学术研究** | Time-R1/STRIDE 极新，2025–26 才出现，尚未出实验室。STRIDE 的 GIFT-Eval #1 是强信号。 |
| 多模态金融文本预测 | **早期落地（局部）** | 情绪因子、事件驱动策略在买方/卖方有真实部署（尤其事件驱动对冲基金），但多为人类设计的因子 + LLM 抽取，而非端到端 LLM 预测。 |
| 概率校准（conformal） | **原型→早期落地** | 理论成熟，工程化工具（MAPIE 等）出现，金融落地案例渐增但未普及。 |
| 防泄漏评估纪律 | **成熟（原则）/ 工程化（实践）** | 原则已是行业常识，但细节执行（文本特征泄漏）仍常出错。 |
| Agent 化预测流水线 | **学术研究→原型** | 2025 起，TS-Agent/AutoML-Agent 验证可行，金融域端到端尚无成熟产品。 |

**买方/卖方实况：** 卖方研究用 LLM 做新闻摘要、事件抽取、研报生成已较普遍（成熟）；买方量化用 LLM 抽情绪因子进多因子模型属早期落地；用 LLM/TSFM 直接做收益分布预测尚处试点，主因是 EMH 先验 + 校准难 + 可解释性要求。Track 2 的设定（分布 + 校准 + uplift 分析）正对准这一"试点→落地"的临界点。

---

## 五、趋势展望（可检验判断）

1. **"小即是美"继续主导 TSFM**：2026–27 年，十亿级以下、原生分布输出的 TSFM（Moirai-MoE、Chronos-2、Time-MoE small）将击败更大模型成为默认 backbone；billion-scale 仅在多域泛化场景保有优势。可检验：GIFT-Eval 头部模型参数量中位数下降。

2. **推理注入式（STRIDE 路线）成为 LLM×TS 的主流接口**：让 LLM 直接吐数字会被淘汰，"LLM 蒸馏推理先验 → 注入 TSFM 连续空间"将成标配，因为它绕过模态鸿沟又保留推理价值。可检验：2026 顶会该范式论文数 ≥5。

3. **文本 uplift 的结论将条件化**：研究社区会放弃"文本全局有没有用"的问法，转向"在何种 regime/资产/事件密度下有用"的条件化分析。Track 2 的 uplift 报告若做分层，将成范例。可检验：2026–27 出现以 conditional uplift 为核心的 benchmark。

4. **Conformal 校准从后处理走向训练时联合优化**：把 quantile loss + conformal coverage 约束联合训练，以攻克 conditional coverage。可检验：出现训练时 conformal-aware 的 TSFM 变体。

5. **Agent 化预测流水线在沙盒竞赛中先成熟**：因沙盒天然约束联网、强制可复现，agent 编排在竞赛场景比开放工业场景更易收敛。Track 2 头部队伍大概率采用"TSFM backbone + 文本 LLM 抽信号 + conformal 校准 + agent 编排"的复合架构。可检验：本届 Agenthon Track 2 top-3 技术报告呈现该模式。
